sih149 test — In-Situ Hardware Diagnostics

Executes all 23 live cryptographic, memory, carver, and safety assertions in-memory. Verifies system integrity before forensic deployment.

# Human-readable visual diagnostic dashboard
sih149 test

# Machine-readable JSON for CI/CD gates
sih149 test --json

Assertion Domains Covered

  • Wiper Subsystem: Zero fill, Ones fill, CSPRNG randomness, sequence correctness (DoD/Gutmann).
  • Safety Guardrails: System directory block, relative traversal escape neutralization, symlink rejection, boot drive lockdown.
  • Carver Validation: Hex decoding, JPEG SOI/EOI parser, PNG IHDR chunk validator, SQLite B-tree page geometry.
  • Cryptographic Primitives: NIST SHA-256 known answer vector, constant-time digest comparison, tamper-evident hash chain verification.

sih149 demo — Autonomous Live Forensic Demo

Provisions an isolated forensic workspace, synthesizes a sector-aligned disk image with embedded artifacts (PNG, JPEG, SQLite, high-entropy corrupt blocks), executes the deep carver, verifies 100% bit-exact SHA-256 matches, and compiles an audit certificate PDF.

# Execute self-contained demo
sih149 demo

# Automated test output for evaluation
sih149 demo --json

sih149 info — Storage Hardware Triage

Discovers attached storage devices, partitions, mountpoints, serial numbers, bus protocols, and SMART health telemetry.

# Enumerate all attached block devices
sudo sih149 info

# Query specific device with detailed SMART telemetry
sudo sih149 info --device /dev/sdb --json

sih149 wipe — Certified Disk Sanitization

Sanitizes block devices adhering to NIST SP 800-88 Rev 1, DoD 5220.22-M (3-Pass & 7-Pass), or Gutmann (35-Pass) standards. Enforces fail-safe lockouts against boot drives.

# Execute DoD 5220.22-M 3-Pass with readback verification
sudo sih149 wipe --device /dev/sdb --method dod3 --verify

# Execute single-pass zero wipe (NIST Clear)
sudo sih149 wipe --device /dev/sdb --method zero --verify

Available Sanitization Methods

zero (0x00 fill) | ones (0xFF fill) | random (CSPRNG stream) | dod3 (3-Pass DoD 5220.22-M) | dod7 (7-Pass DoD ECE) | gutmann (35-Pass magnetic matrix)

sih149 shred — File & Directory Sanitization

Multi-pass file shredder with metadata scrambling, successive random renames, cluster slack scrubbing, and file truncation.

# Securely shred a sensitive document (3 passes, 8 renames)
sih149 shred --target /path/to/evidence.pdf --passes 3 --renames 8 --yes

# Recursively shred an entire directory tree
sih149 shred --target /path/to/case_folder --passes 7 --yes

sih149 recover — Chunk-Aware File Carver

Scans raw storage devices, disk images (.dd, .raw, .img), or E01 evidence containers. Reconstructs files based on internal structural boundaries rather than raw heuristic guessing.

# Carve all supported file formats from evidence source
sudo sih149 recover --source /dev/sdb --out-dir /mnt/evidence

# Filter specific formats (e.g. PNG and SQLite only)
sudo sih149 recover --source /dev/sdb --out-dir /mnt/evidence --types png,sqlite

sih149 firmware-erase — Silicon-Level Erase

Issues hardware controller commands to sanitize flash memory overprovisioning areas, wear-leveling pools, and retired bad blocks that software overwrites cannot touch.

# NVMe Cryptographic Erase (scrambles AES media encryption key)
sudo sih149 firmware-erase --device /dev/nvme0n1 --action nvme-crypto-erase --yes

# ATA Enhanced Secure Erase
sudo sih149 firmware-erase --device /dev/sda --action ata-enhanced-secure-erase --yes

sforge — Full-Screen Terminal TUI

Zero-latency terminal interface built with Ratatui and Crossterm. Provides interactive device selection, live sector progress bars, and real-time Shannon entropy heatmaps.

# Launch TUI interface
sudo sforge

Keyboard Navigation

  • [↑ / ↓] Navigate device list or operation menus
  • [Enter] Select target or launch operation
  • [Tab] Switch between active inspection panes
  • [Space] Select individual file carving candidates
  • [Q / Esc] Exit to terminal
