Flashing Guides for USB Thumb Drives

A Linux / macOS Terminal (dd)

Write directly to raw block device (replace /dev/sdX with your USB drive):

# Identify USB disk path
sudo lsblk

# Flash ISO image with fsync
sudo dd if=raze-carve-live-0.1.0-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync

B Multi-Boot Drive (Ventoy)

Ventoy allows keeping multiple ISOs on a single USB drive with zero reformatting:

# 1. Install Ventoy to your USB drive
# 2. Copy ISO directly to the Ventoy partition:
cp raze-carve-live-0.1.0-x86_64.iso /media/ventoy/

# 3. Boot any PC and select RAZE-CARVE from menu

C Windows (Rufus)

Open Rufus, select your USB drive, choose raze-carve-live-0.1.0-x86_64.iso, select GPT / UEFI (or MBR / BIOS), and choose DD Image mode when prompted.

D Cross-Platform (BalenaEtcher)

Launch BalenaEtcher on Windows, Mac, or Linux, select Flash from file, pick the ISO, select your USB drive, and click Flash!.

Docker Execution Recipes

1 Run Background Web Workstation

Starts the RAZE-CARVE server accessible from any web browser on port 7878:

docker run -d \
  --name razecarve \
  --privileged \
  -v /dev:/dev \
  -v $(pwd)/case_data:/root/cases \
  -p 7878:7878 \
  normie69k/razecarve:latest

# Open browser at: http://localhost:7878

2 Run One-Shot CLI Inspection

Execute command-line disk enumeration or carving without opening web ports:

# Enumerate storage devices
docker run --rm --privileged \
  -v /dev:/dev \
  normie69k/razecarve:latest \
  sih149 info

# Run 23 Subsystem Diagnostics
docker run --rm normie69k/razecarve:latest sih149 test

Manual Installation into System Path

Install binaries into /usr/local/bin and verify execution:

# Make executable and install to standard path
sudo install -m 755 target/release/sih149 /usr/local/bin/sih149
sudo install -m 755 target/release/sforge /usr/local/bin/sforge

# Verify installation
sih149 test
sforge --version

Compile RAZE-CARVE from Clean Source

Build the entire zero-warning Rust workspace with cargo, verify the 181 unit tests, and compile the frontend.

1 Prerequisites

Install Rust toolchain and Linux development headers:

# On Debian / Ubuntu
sudo apt install -y build-essential curl pkg-config libssl-dev libsqlite3-dev

# On Arch Linux
sudo pacman -S --needed base-devel rustup openssl sqlite

# Ensure Rust stable is active
rustup default stable

2 Clone & Compile Workspace

Clone the repository and compile all workspace crates in release mode:

git clone https://github.com/razecarve/razecarve.git
cd razecarve

# Run verification test suite
cargo test --workspace

# Compile optimized release binaries
cargo build --release --workspace

# Binaries output to: target/release/sih149, sforge, raze-carve-desktop
